PHONE CODE

Politique de confidentialité

Dernière mise à jour : 10 octobre 2026

Phone Code ne collecte aucune donnée personnelle. Pas de compte, pas de publicité, pas de traceur, pas de statistiques d’utilisation : vos projets et vos réglages restent sur votre appareil.

Qui sommes-nous

Phone Code est une application d’édition de code pour téléphone et tablette, éditée par Joachim Da Silva. Cette politique explique quelles informations l’application traite, où elles sont conservées et comment vous en gardez le contrôle.

Données collectées par l’éditeur

Aucune. Phone Code ne possède pas de serveur : l’application ne nous envoie ni vos fichiers, ni vos réglages, ni identifiant d’appareil, ni statistique d’utilisation. Elle n’intègre aucun outil d’analyse, de publicité ou de suivi, et ne vous demande pas de créer un compte.

Données conservées sur votre appareil

Pour fonctionner, l’application enregistre localement, dans son espace privé :

  • vos projets et leurs fichiers, y compris l’historique Git ;
  • vos réglages : thème, taille du texte, préférences de l’éditeur, fichiers récents et dernier projet ouvert ;
  • le nom et l’adresse e-mail d’auteur des commits, si vous les renseignez ;
  • vos identifiants Git (nom d’utilisateur et jeton d’accès), si vous choisissez de les mémoriser : ils sont chiffrés par le système (Trousseau sur iOS, Keystore sur Android).

Ces données ne quittent pas votre appareil, sauf dans les cas ci-dessous, toujours à votre initiative. Nous n’y avons pas accès.

Connexions réseau, à votre initiative

  • Git : quand vous clonez, tirez (pull) ou poussez (push) un dépôt, l’application échange directement avec le serveur que vous avez indiqué (GitHub, GitLab…), en HTTPS. Ce serveur reçoit vos identifiants et le contenu de vos commits, dont le nom et l’e-mail d’auteur. Ces échanges relèvent de la politique de confidentialité de ce service.
  • Aperçu en direct : la page affichée peut charger les ressources externes (polices, scripts, images) que votre propre code référence ; ces requêtes partent vers les adresses écrites dans votre code.
  • Liens externes : le bouton « Découvrir Livrook » ouvre la fiche de l’application dans l’App Store ou Google Play (ou le site livrook.com). Un identifiant de campagne anonyme (« phonecode ») est ajouté au lien pour compter les installations ; aucune information vous concernant n’est transmise.

Fichiers du téléphone et partage

L’application n’accède aux fichiers de votre téléphone que lorsque vous choisissez vous-même un fichier à importer ou un emplacement où enregistrer un export, via le sélecteur du système. Le partage d’un projet passe par la feuille de partage du système, vers l’application ou la personne que vous choisissez.

Autorisations

Phone Code n’utilise que l’accès à Internet (pour Git et l’aperçu en direct). Elle ne demande accès ni à votre position, ni à vos contacts, ni à l’appareil photo, ni au micro, ni à vos photos.

Services des stores

Apple (App Store) et Google (Google Play) traitent les données liées au téléchargement de l’application selon leurs propres politiques. Si vous avez accepté de partager les diagnostics avec les développeurs dans les réglages de votre appareil, ils peuvent nous fournir des rapports de plantage anonymes et agrégés, que nous utilisons uniquement pour corriger les erreurs.

Conservation et suppression

Vous gardez le contrôle total de vos données :

  • supprimer un projet : menu ⋮ du projet → Supprimer ;
  • oublier les identifiants Git : Réglages → Git → Oublier les identifiants ;
  • effacer vos réglages : Réglages → Rétablir les réglages par défaut ;
  • tout effacer : désinstaller l’application supprime l’ensemble de ses données de l’appareil.

Pour conserver vos projets, exportez-les au format .zip (menu ⋮ du projet → Exporter) ou poussez-les sur un dépôt Git.

Sécurité

Les identifiants Git sont chiffrés par le système d’exploitation et les échanges Git passent par HTTPS. Les fichiers de vos projets sont stockés dans l’espace privé de l’application, inaccessible aux autres applications.

Enfants

L’application ne collecte aucune donnée personnelle, y compris celles des enfants.

Vos droits

Conformément au Règlement général sur la protection des données (RGPD), vous disposez de droits d’accès, de rectification et d’effacement. Comme nous ne détenons aucune donnée vous concernant, ces droits s’exercent directement dans l’application (voir « Conservation et suppression »). Pour toute question, écrivez-nous ; vous pouvez aussi saisir la CNIL (cnil.fr).

Modifications

Si cette politique évolue, la nouvelle version sera publiée dans l’application et sur sa page web, avec sa date de mise à jour. Une fonctionnalité qui transmettrait des données ne serait ajoutée qu’après mise à jour de cette politique.
